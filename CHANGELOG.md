## [0.1.0] - 2026-11-18

### Added
- Vehicle records with year, make, model and odometer.
- Service, repair and inspection history with costs and notes.
- Automatic odometer updates and per-vehicle cost totals.
- SQLite persistence stored in the `data/` directory.
- Docker image and Docker Compose deployment.
- Health endpoint and container health check.
- Application version shown beneath the application name.
- In-app Changelog page linked from the navigation and footer.
- Automated behavioural tests run against the candidate image.
- Backup, restore, update and release scripts.
- README, security policy and MIT license.
